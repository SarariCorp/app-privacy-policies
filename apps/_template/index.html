Starter template

Reusable App Policy Template

Copy this folder to create each new app policy route: /apps/<app-slug>/.

Self-contained app folder requirement

Each app folder must include both an index.html policy page and an app logo asset placeholder or final logo file.

When creating a new app route, copy this placeholder and rename/replace it with the app's approved logo asset.

Required placeholders to replace

  • [REPLACE APP NAME]
  • [REPLACE COMPANY NAME]
  • [REPLACE FREE/PAID/SUBSCRIPTION]
  • [REPLACE WITH EXACT DATA TYPES OR "No personal data is collected directly by the app."]
  • [REPLACE WITH SPECIFIC USES OR "Not applicable because no data is collected."]
  • [REPLACE WITH ONLY THE SERVICES ACTUALLY USED, such as analytics, ads, crash reporting, or none.]
  • [REPLACE WITH RETENTION PERIODS OR "No personal data is stored by us."]
  • [REPLACE WITH APP-SPECIFIC CHILDREN PRIVACY STATEMENT.]
  • [REPLACE WITH REASONABLE TECHNICAL/ORGANIZATIONAL SAFEGUARDS USED.]
  • [REPLACE CONTACT EMAIL]
  • [REPLACE DATE]

After replacement, add the new app card on the landing page and keep all links relative for GitHub Pages project-site compatibility.
